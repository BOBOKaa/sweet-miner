# 甜心矿工

一个竖屏、打开就能玩的黄金矿工小游戏。仙女棒左右摇摆，点一下屏幕把金子、钻石和小心心带回家。一共一百关，后面越来越紧。画面是奶油粉、薄荷和浅金的甜美风格，适合手机浏览器，也方便以后嵌进网页或套一层小程序外壳。

不需要登录，不接任何小红书接口或原生 SDK。进度保存在这台手机的浏览器里。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开终端里显示的本地地址。手机和电脑都能玩：手机竖屏点按，电脑也可以用鼠标，空格发射。

## 打包静态文件

```bash
npm run build
npm run preview
```

构建结果在 `dist/`。这是纯静态页面，把整个目录上传到任意静态托管（对象存储、GitHub Pages、自己的 Nginx）就能用链接分享。资源使用相对路径，放在子目录里也可以打开。

以后如果要包成小程序，用 web-view 打开这个 H5 地址即可，游戏本身不依赖小程序账号。

## 怎么玩

- 仙女棒会自己摇摆，点屏幕或下方爱心，沿当前方向射出。
- 抓到的东西会拉回来。小金块和钻石很轻，大石头又重又慢。
- 过关目标是一直累加的，存款也算在里面。倒计时结束前还可以继续挖，多出来的金币也会存进存款。小铺花掉的钱，下一关要再挖回来。
- 一共一百关。前面松一点，从中段开始目标更高、时间更紧、石头也更多。
- 没达到目标可以重试本关，已经买好的道具还会留着。

检查关卡是否都够得着、宝物没有叠在一起、并且不买道具也能过关：

```bash
npm run balance
```

## 源码

- `src/main.ts`：界面流程、商店、存档
- `src/game/engine.ts`：仙女棒的挥动、发射和关卡循环
- `src/game/levels.ts`：一百关。前十关是手摆的，后面按固定种子生成
- `src/game/art.ts`：角色、矿洞和宝物的绘制
- `src/style.css`：界面样式

音效和背景音乐都由代码实时合成，不下载外部音频。点一下屏幕就会出声，右上角的喇叭可以关掉，划掉表示静音。标题字体是 [ZCOOL KuaiLe](https://fonts.google.com/specimen/ZCOOL+KuaiLe)（SIL Open Font License），只嵌入了游戏里用到的字。
